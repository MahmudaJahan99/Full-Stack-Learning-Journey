# Subscript and Superscript

## `<sub>` — Subscript

`<sub>` displays text slightly below the normal text line.

```html
H<sub>2</sub>O
```

Result:

**H₂O**

Useful for:

- Chemical formulas
- Mathematical notation
- Scientific notation

---

## `<sup>` — Superscript

`<sup>` displays text slightly above the normal text line.

```html
x<sup>2</sup>
```

Result:

**x²**

Useful for:

- Exponents
- Mathematical notation
- Ordinal numbers
- Footnote references
