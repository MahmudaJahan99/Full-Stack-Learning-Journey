# Line Break — `<br>`

`<br>` creates a line break within text.

Example

```html
<p>
  Mahmuda Jahan<br />
  Dhaka, Bangladesh<br />
  Frontend Developer
</p>
```

## `<br>` vs `<p>`

Use `<p>` when you have **separate paragraphs**.

Use `<br>` when you need a **line break within the same piece of content**.
