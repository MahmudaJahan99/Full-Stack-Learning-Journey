# `<mark>` — Highlighted Text

`<mark>` represents text that is highlighted or marked because it is relevant in the current context. Browsers usually display it with a yellow background.

Example:

```html
<p>
  HTML provides the structure of a webpage.
  <mark>CSS</mark> is responsible for presentation.
</p>
```

Conceptually:

```text
HTML provides the structure of a webpage.
CSS
^^^
highlighted
```
