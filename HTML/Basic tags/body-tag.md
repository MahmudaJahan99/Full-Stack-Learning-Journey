# `<body>`

The `<body>` element contains the **content of the HTML document**. This is where most of the content users interact with is placed. Examples include:

- headings
- paragraphs
- images
- links
- buttons
- lists
- forms
- videos
- navigation
- articles
- sections

Example:

```html
<body>
  <h1>My Portfolio</h1>
  <p>Hello! I'm learning frontend development.</p>
  <a href="projects.html">View my projects</a>
</body>
```

The browser renders the content inside the body as part of the webpage.
