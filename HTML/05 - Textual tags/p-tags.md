# Paragraph — `<p>`

The `<p>` element represents a paragraph. The browser automatically treats each `<p>` as a separate paragraph.

Example:

```html
<p>
  HTML provides the structure of a webpage. CSS controls its presentation, while
  JavaScript adds behavior and interactivity.
</p>
<p>Second paragraph.</p>
```

Conceptually:

```text
First paragraph.
       ↓
   [space]
       ↓
Second paragraph.
```
