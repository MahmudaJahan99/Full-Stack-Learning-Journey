# Data Structures

> Data structures are ways of **organizing and storing data** so that we can work with it efficiently. JavaScript provides several built-in data structures. They can be grouped into:

```text
                           DATA STRUCTURES
                                |
        ┌───────────────────────┼───────────────────────┐
        |                       |                       |
Indexed Collections      Keyed Collections         Structured Data
        |                       |                       |
  ┌─────┴─────┐           ┌─────┼──────┬─────┐          |
  |           |           |     |      |     |          |
Arrays      Typed        Map  WeakMap Set WeakSet      JSON
            Arrays
```
