# Arithmetic Operators

**Arithmetic operators** perform mathematical operations.

| Operator | Operation      |
| -------- | -------------- |
| `+`      | Addition       |
| `-`      | Subtraction    |
| `*`      | Multiplication |
| `/`      | Division       |
| `%`      | Remainder      |
| `**`     | Exponentiation |
| `++`     | Increment      |
| `--`     | Decrement      |

```javascript
10 + 5;
// 15

10 - 5;
// 5

10 * 5;
// 50

10 / 5;
// 2

10 % 3;
// 1

10 % 2 === 0;
// true

2 ** 3;
// 8
```
