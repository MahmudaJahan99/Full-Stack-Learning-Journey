# What Is a Domain Name?

A **domain name** is a human-readable name used to identify a website or Internet service.It provides a convenient human-readable way to access a server or Internet service.

Example:

```text
google.com
github.com
example.com
```

Computers communicate using IP addresses:

```text
93.184.216.34
```

## Domain Name Structure

Consider:

```text
www.example.com
```

It can be broken into parts:

```text
www     .     example     .     com
│               │                │
│               │                └── Top-Level Domain
│               │
│               └── Domain Name
│
└── Subdomain
```

---

### Top-Level Domain

Examples:

```text
.com
.org
.net
.edu
```

There are also country-code TLDs:

```text
.bd
.uk
.in
.jp
```

---

## Subdomain

A subdomain is a domain that exists under another domain.

Example:

```text
blog.example.com
```

Here:

```text
blog
  ↓
Subdomain

example
  ↓
Domain

com
  ↓
TLD
```
