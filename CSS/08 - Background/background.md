# CSS Background

The CSS `background` properties control the **background appearance of an HTML element**. A background can be:

- A solid color
- An image
- A gradient
- Positioned in a specific location
- Fixed or scrolled with the page

---

## Background Color

The `background-color` property sets a **solid color** as the background of an element.

Syntax:

```css
selector {
  background-color: value;
}
```

Example:

```css
body {
  background-color: lightblue;
}
```
